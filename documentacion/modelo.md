# Modelo incluido

La versión 1.0 utiliza los pesos preentrenados `yolo11n.pt` de Ultralytics, sin entrenamiento propio, para detectar únicamente la clase persona. El archivo se conserva en Git para que un clon incluya el modelo necesario para construir el contenedor.

- Ruta: `servicio_ia/modelos/yolo11n.pt`.
- Procedencia de esta copia: pesos ya presentes en el proyecto SistemaAforo original.
- Referencia del proveedor: [Ultralytics YOLO11](https://docs.ultralytics.com/models/yolo11/).
- Biblioteca y modelos sujetos a las condiciones del proveedor: [licencia de Ultralytics](https://www.ultralytics.com/license) y [licencia del repositorio](https://github.com/ultralytics/ultralytics/blob/main/LICENSE). La inclusión de los pesos no cambia esas condiciones.
